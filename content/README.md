# JVM 系统学习手册

## 导读：跟着一个 Java 程序走完一生

JVM 的知识点看起来很散：内存区域、类加载、GC、收集器、调优……其实它们都是同一个程序在不同阶段遇到的事。按程序“从源码到运行、从出生到回收、从上线到出问题”的顺序学，比按题背更容易记住。

整条主线可以这样理解：

1. **代码怎么跑**：javac 把源码编译成字节码，JVM 为每次方法调用压一个栈帧，在栈帧里逐条执行字节码；跑得多的热点代码，再由 JIT 编译成机器码。
2. **东西放哪**：运行时数据区分成线程私有的栈、程序计数器，和线程共享的堆、方法区。类加载器把类读进方法区，new 出来的对象放进堆。
3. **对象怎么死**：GC 从 GC Roots 出发找活对象，剩下的就是垃圾；按对象寿命分代，用不同的算法回收。
4. **怎么回收得更好**：收集器的演进就是把停顿越切越短，从 Serial 到 ZGC。
5. **出了问题怎么查**：用 jstat、jcmd、jstack、GC 日志和堆转储建立证据链。

### 怎么用这份文档

这份手册写给会写 Java、对 JVM 只有零散印象（听说过堆、栈、GC）的人，目标是理解原理、能动手观察，并能应付面试。内容按面试的主线取舍：内存结构、垃圾回收（可达性分析、回收算法、Minor GC 与 Full GC、CMS 与 G1）、类加载与双亲委派、内存问题排查讲透；字节码、JIT 只讲理解主线所需的部分。操作系统和并发只在用到的地方一两句话交代；锁和对象头的关系见姊妹篇 [learn-juc](https://github.com/erha1499/learn-juc) 单元三。

每个单元都按同一个节奏组织：

1. **先看现象，再学原理**：单元开头列出学完能做到的几件事。能用代码复现的问题（`i = i++` 还是 0、类没有按预期初始化、对象明明不用了却回收不掉），先给出可运行的代码和真实结果，再解释为什么。标着「深入一层（可跳过）」的部分是源码和底层细节，第一遍可以跳过。
2. **动手**：网页版在关键位置嵌了可以一步一步执行的演示；文中的示例代码都在仓库的 `examples/` 目录里，建议亲手跑一遍，再用 `javap`、`jstat`、`jcmd` 看一看。
3. **检验**：单元末尾的「面试这样说」是原理的口述压缩版，读懂原理后再看。最后合上文档做自测题，答不上来就回看正文。

示例代码都在 JDK 17（64 位 HotSpot，macOS，Apple M2 8 核，24GB 内存）上实际跑过，个别地方用 JDK 21 对比。不同机器上的数字会有出入，但趋势和结论一致。
